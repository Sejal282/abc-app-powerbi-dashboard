ABC App Analytics Dashboard

Data Analytics & Business Intelligence Project created using Power BI. This project analyzes user behavior, EV charging activity, gaming engagement, wallet transactions, and revenue performance across the ABC App ecosystem.

Live Dashboard GitHub Repository Project PPT

Project Overview

The ABC App Analytics Dashboard helps businesses understand customer activity and operational performance through interactive visualizations and KPI tracking. The dashboard combines multiple datasets including user data, EV charging sessions, gaming activity, wallet transactions, and revenue insights to support business decision-making.

Key KPIs

  • Total Users
  • Total Revenue
  • Total EV Charging Sessions
  • Total Energy Consumed
  • Wallet Transactions
  • Gaming Usage Analytics
  • User Retention Rate
  • Referral Source Analysis
  • Peak Usage Hours

Tools & Technologies Used

  • Power BI
  • Microsoft Excel
  • CSV Datasets
  • Data Cleaning
  • Data Modeling
  • DAX Measures
  • Dashboard Visualization
  • GitHub Pages

Business Insights Generated

  • Identified top-performing game categories
  • Analyzed EV charging demand patterns
  • Tracked customer wallet spending trends
  • Measured user engagement and retention
  • Detected revenue growth opportunities
