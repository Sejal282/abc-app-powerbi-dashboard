ABC App Analytics Dashboard

Data Analytics & Business Intelligence project created using Power BI. This dashboard analyzes user behavior, EV charging usage, gaming activity, wallet transactions, and business KPIs across the ABC App ecosystem.

Live Dashboard GitHub Repository Project PPT

Project Overview

The project focuses on analyzing the complete ABC App ecosystem including EV charging, wallet usage, gaming activity, and user engagement. The dashboard provides actionable business insights using data visualization.

Key KPIs

  • Total Users
  • Total Revenue
  • EV Charging Sessions
  • Total Energy Consumed
  • Wallet Transactions
  • Game Usage Analytics
  • User Retention & Activity

Tools & Technologies

  • Power BI
  • Excel / CSV
  • Data Cleaning
  • Data Modeling
  • DAX Measures
  • Dashboard Design
  • GitHub Pages
