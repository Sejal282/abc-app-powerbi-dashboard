ABC App Analytics Dashboard

A Data Analytics and Business Intelligence project built using Power BI. This dashboard analyzes user behavior, EV charging activity, wallet transactions, gaming usage, revenue trends, and customer engagement across the ABC App ecosystem.

Live Dashboard GitHub Repository Project PPT

Project Overview

This project focuses on analyzing the complete ABC App ecosystem. The dashboard provides insights into EV charging usage, wallet transactions, gaming engagement, user growth, and revenue generation using interactive visualizations and KPIs.

Key KPIs

  • Total Users
  • Total Revenue
  • EV Charging Sessions
  • Energy Consumed
  • Wallet Transactions
  • Gaming Usage
  • User Retention

Tools & Technologies

  • Power BI
  • Excel / CSV
  • Data Cleaning
  • Data Modeling
  • DAX Measures
  • Dashboard Design
  • GitHub Pages

Business Insights

  • Identified top-performing games
  • Analyzed charging patterns
  • Tracked wallet spending trends
  • Measured user engagement
  • Detected revenue opportunities
